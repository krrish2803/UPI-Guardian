How it works

5 steps. 5 seconds.

Fully automated pipeline — upload an image, the server calls NVIDIA NIM, and you get a verdict in seconds.

01
Web Upload

User uploads a screenshot

Any UPI payment request, QR scan, or forwarded suspicious message. Zero friction — no typing, no copying IDs.

02
Python Backend

Server routes the image to NVIDIA NIM

Upload triggers a POST to the server. Image + fraud prompt sent to meta/llama-3.2-90b-vision-instruct via NVIDIA NIM API.

03
NVIDIA NIM API

AI extracts + analyses

OCR + fraud pattern reasoning in one call. Extracts UPI ID, merchant name, amount, and flags risk signals using meta/llama-3.2-90b-vision-instruct.

04
In-Memory Database

Check logged to fraud database

Every scan appended to the server's in-memory log. Builds a session-based scam database (resets on server restart).

05
Result Display

Verdict displayed instantly

Risk badge + confidence gauge + bullet reasons + bilingual verdict — back to the user in under 5 seconds.
